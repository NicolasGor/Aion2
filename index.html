DPS meter sullo Steam Deck

📋 Incollare in Konsole: Ctrl+Shift+V, poi Invio

🔒 Le password non si vedono mentre le scrivi: è normale

⏳ Prima di incollare il comando successivo, aspetta che torni (deck@steamdeck ~)$

Installazione, una volta sola

1

Modalità Desktop, poi apri Konsole

STEAM → Spegni → Passa al desktop. Konsole è nel menu in basso a sinistra.

2

Crea la password del Deck

passwd

Scrivila due volte e segnatela: ti servirà nei passi successivi.

3

Prepara lo spazio

sudo mkdir -p /home/.a2tools-containers
sudo tee /etc/containers/storage.conf <<'EOF'
[storage]
driver = "overlay"
graphroot = "/home/.a2tools-containers"
runroot = "/run/containers/storage"
EOF

Il secondo comando si incolla tutto insieme, in una volta sola.

4

Crea la scatola

distrobox create --root --name a2tools --image archlinux:latest

Se chiede [Y/n]: scrivi Y e Invio. Ci mette qualche minuto.

5

Scarica e installa il meter

curl -LO https://cdn.a2tools.app/linux/a2tools-dps-meter-latest-x86_64.pkg.tar.zst
distrobox enter --root a2tools -- sudo pacman -Syu --noconfirm
distrobox enter --root a2tools -- sudo pacman -U --noconfirm ~/a2tools-dps-meter-latest-x86_64.pkg.tar.zst

Il secondo comando, la prima volta, prepara la scatola per qualche minuto. Se chiede una password, usa quella del Deck. Alla fine del terzo deve comparire A2Tools DPS Meter may now capture packets.

Ogni volta che giochi

▶

Prima il gioco, poi il meter

In Modalità Desktop avvia AION 2 da Steam, poi incolla in Konsole:

distrobox enter --root a2tools -- a2tools-dps-meter

Tieni Konsole aperta. La volta dopo basta la freccia ↑ e poi Invio.

★

Icona sul desktop (una volta sola)

Incolla tutto insieme in Konsole e premi Invio. Sul desktop compare «A2Tools DPS Meter».

cat > ~/Desktop/A2Tools.desktop <<'EOF'
[Desktop Entry]
Type=Application
Name=A2Tools DPS Meter
Exec=distrobox enter --root a2tools -- a2tools-dps-meter
Icon=utilities-system-monitor
Terminal=true
EOF
chmod +x ~/Desktop/A2Tools.desktop

Da qui in poi: avvia il gioco, poi doppio clic sull'icona. Si apre Konsole: non chiudere quella finestra.

🔓

Avvio senza password (una volta sola)

Dopo questo, meter, Onboard e scatola non chiedono più la password. Il resto del Deck sì.

echo "deck ALL=(root) NOPASSWD: $(command -v podman)" > /tmp/a2tools && sudo visudo -cf /tmp/a2tools && sudo install -m 440 /tmp/a2tools /etc/sudoers.d/a2tools

Chiede la password del Deck un'ultima volta. Se compare parsed OK è fatto. Per toglierlo: sudo rm /etc/sudoers.d/a2tools

★

Meter sempre sopra il gioco (una volta sola)

Nel gioco: modalità schermo In finestra, risoluzione 1280×800.

Impostazioni di sistema → Gestione delle finestre → Regole delle finestre. Due regole:

Meter: Aggiungi nuova → Rileva le proprietà della finestra → clic sul meter → Aggiungi proprietà «Mantieni sopra le altre»: Forza, Sì.

Gioco: Aggiungi nuova → Classe della finestra «Non importante» → Aggiungi proprietà «Titolo della finestra»: Corrispondenza esatta, AION2. Poi su Forza: Posizione 0×0, Dimensione 1280×800, Nessuna barra del titolo e cornice: Sì.

Barra in basso: clic destro → Modifica pannello → Visibilità «Eludi le finestre».

⌨

Tastiera a schermo per il gioco (Onboard)

In Modalità Desktop la tastiera di Steam (STEAM+X) non scrive nel gioco. Installa Onboard, una volta sola:

distrobox enter --root a2tools -- sudo pacman -S --noconfirm onboard

Per aprirla:

distrobox enter --root a2tools -- onboard

Clicca nella casella del gioco, poi premi i tasti su Onboard. Non chiudere Konsole. ⚠️ Da provare.

Password rifiutata anche se è giusta

!

Dopo 3 errori il Deck blocca la password

1. Chiudi Konsole e aspetta 15 minuti senza provare nessuna password (né meter, né Onboard, né Discover). Ogni tentativo allunga il blocco.

2. Guarda i tentativi sbagliati (non chiede password). L'ultimo deve essere di almeno 10 minuti fa:

faillock --user deck

3. Una prova sola: Malusc spento, scrivi piano, un solo Invio. Va bene anche il passo 🔓 al posto di questo.

sudo true

Torna (deck@steamdeck ~)$ senza errori: è sbloccata. Compare Riprovare: non scrivere altro, chiudi Konsole e manda una foto.

Se si blocca

«insufficient space» al passo 4: incolla sudo podman system reset --force, poi rifai i passi 3 e 4.
Il meter non segna danni: rifai l'ultimo comando del passo 5.
Altro: fai una foto a Konsole e mandala a Claude.
