DPS meter sullo Steam Deck

📋 Incollare in Konsole: pulsante Incolla in alto, oppure Ctrl+Shift+V. Poi Invio

🔒 Le password non si vedono mentre le scrivi: è normale

⏳ Prima di incollare il comando successivo, aspetta che torni (deck@steamdeck ~)$

Ogni volta che giochi

▶

Prima il gioco, poi il meter

Modalità Desktop → avvia AION 2 da Steam → doppio clic sull'icona «A2Tools DPS Meter». Non chiudere la finestra di Konsole che si apre.

Installazione, una volta sola

1

Modalità Desktop, poi apri Konsole

STEAM → Spegni → Passa al desktop. Konsole è nel menu in basso a sinistra.

2

Crea la password del Deck

passwd

Solo lettere minuscole e numeri: la tastiera di Steam a volte non manda le maiuscole. Scrivila due volte e segnatela.

3

Prepara lo spazio

sudo mkdir -p /home/.a2tools-containers
sudo tee /etc/containers/storage.conf <<'EOF'
[storage]
driver = "overlay"
graphroot = "/home/.a2tools-containers"
runroot = "/run/containers/storage"
EOF

Il secondo comando si incolla tutto insieme, in una volta sola.

4

Crea la scatola

distrobox create --root --name a2tools --image archlinux:latest

Se chiede [Y/n]: scrivi Y e Invio. Ci mette qualche minuto.

5

Scarica e installa il meter

curl -LO https://cdn.a2tools.app/linux/a2tools-dps-meter-latest-x86_64.pkg.tar.zst
distrobox enter --root a2tools -- sudo pacman -Syu --noconfirm
distrobox enter --root a2tools -- sudo pacman -U --noconfirm ~/a2tools-dps-meter-latest-x86_64.pkg.tar.zst

Il secondo, la prima volta, prepara la scatola per qualche minuto. Alla fine del terzo: A2Tools DPS Meter may now capture packets.

6

Icona sul desktop

Incolla tutto insieme. Sul desktop compare «A2Tools DPS Meter».

cat > ~/Desktop/A2Tools.desktop <<'EOF'
[Desktop Entry]
Type=Application
Name=A2Tools DPS Meter
Exec=distrobox enter --root a2tools -- a2tools-dps-meter
Icon=utilities-system-monitor
Terminal=true
EOF
chmod +x ~/Desktop/A2Tools.desktop

Anche nel menu e nella barra in basso:

mkdir -p ~/.local/share/applications && cp ~/Desktop/A2Tools.desktop ~/.local/share/applications/ && chmod +x ~/.local/share/applications/A2Tools.desktop

Poi: menu (icona in basso a sinistra) → cerca «A2Tools DPS Meter» → clic destro → Fissa nel gestore dei processi. Uguale per «Captcha».

7

Avvio senza password

echo "deck ALL=(root) NOPASSWD: $(command -v podman)" > /tmp/a2tools && sudo visudo -cf /tmp/a2tools && sudo install -m 440 /tmp/a2tools /etc/sudoers.d/zz-a2tools

Deve comparire analisi effettuata correttamente. Verifica: questo non chiede password e stampa podman version …

sudo -n podman --version

Se il meter chiede ancora la password, prima incolla questo (chiede la password una volta), poi rifai la verifica:

sudo mv /etc/sudoers.d/a2tools /etc/sudoers.d/zz-a2tools
8

Meter sempre sopra il gioco

Nel gioco: modalità schermo In finestra, risoluzione 1280×800.

Impostazioni di sistema → Gestione delle finestre → Regole delle finestre. Due regole:

Meter: Aggiungi nuova → Rileva le proprietà della finestra → clic sul meter → Aggiungi proprietà «Mantieni sopra le altre»: Forza, Sì.

Gioco: Aggiungi nuova → Classe della finestra «Non importante» → Aggiungi proprietà «Titolo della finestra»: Corrispondenza esatta, AION2. Poi su Forza: Posizione 0×0, Dimensione 1280×800, Nessuna barra del titolo e cornice: Sì.

Barra in basso: clic destro → Modifica pannello → Visibilità «Eludi le finestre».

⌨

Captcha: programmino per copiare e incollare

La tastiera di Steam non scrive nel gioco. Si scrive in una finestrella e si incolla nel gioco con un tasto.

1. Installa (nella scatola del meter):

distrobox enter --root a2tools -- sudo pacman -S --noconfirm --needed python tk

2. Programma e icona «Captcha» (incolla tutto insieme):

mkdir -p ~/.local/bin ~/.local/share/applications
cat > ~/.local/bin/captcha.py <<'EOF'
import tkinter as tk
root = tk.Tk()
root.title("Captcha")
root.geometry("440x150")
root.attributes("-topmost", True)
v = tk.StringVar()
e = tk.Entry(root, textvariable=v, font=("monospace", 24))
e.pack(fill="x", padx=10, pady=(10, 6))
row = tk.Frame(root)
row.pack(fill="x", padx=10)
info = tk.Label(root, text="Invio = Copia")
info.pack(pady=6)
def copia(*_):
    t = v.get().strip()
    if not t:
        return
    root.clipboard_clear()
    root.clipboard_append(t)
    root.update()
    info.config(text="Copiato. Nel gioco premi il tasto Ctrl+V")
def pulisci():
    v.set("")
    info.config(text="Invio = Copia")
    e.focus_set()
tk.Button(row, text="Copia", font=("sans", 16, "bold"), command=copia).pack(side="left", expand=True, fill="x")
tk.Button(row, text="Pulisci", font=("sans", 16), command=pulisci).pack(side="left", padx=(8, 0))
e.bind("<Return>", copia)
e.focus_set()
root.mainloop()
EOF
cat > ~/.local/share/applications/Captcha-a2.desktop <<'EOF'
[Desktop Entry]
Type=Application
Name=Captcha
Exec=distrobox enter --root a2tools -- python3 /home/deck/.local/bin/captcha.py
Icon=input-keyboard
Terminal=false
EOF
chmod +x ~/.local/share/applications/Captcha-a2.desktop
cp ~/.local/share/applications/Captcha-a2.desktop ~/Desktop/

3. Tasto Ctrl+V nel layout: in gioco STEAM → Impostazioni controller → Modifica layout → un tasto libero (es. L4) → Ctrl, poi ingranaggio → Aggiungi comando → V.

Uso: doppio clic su «Captcha», clic nella casella, scrivi con STEAM+X, Invio. Poi clicca nella casella del gioco e premi L4.

Nella barra in basso: menu → cerca «Captcha» → clic destro → Fissa nel gestore dei processi.

Se si blocca

«insufficient space» al passo 4: incolla sudo podman system reset --force, poi rifai i passi 3 e 4.
Il meter non segna danni: rifai l'ultimo comando del passo 5.
Password rifiutata anche se giusta: dopo 3 errori il Deck la blocca per 10 minuti. Aspetta, oppure riavvia il Deck.
Aggiornare il meter: rifai il primo e il terzo comando del passo 5.
Altro: fai una foto a Konsole e mandala a Claude.
